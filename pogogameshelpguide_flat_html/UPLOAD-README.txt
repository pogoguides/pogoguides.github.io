UPLOAD INSTRUCTIONS
1. Extract this ZIP file.
2. Open your GitHub repository.
3. Choose Add file > Upload files.
4. Select index.html and all the individual .html files together.
5. Upload them to the repository root (do not put them inside another folder).
6. Commit changes and wait for GitHub Pages deployment.

The structure is intentionally flat, matching the example screenshot:
index.html
how-to-example.html
another-guide.html
